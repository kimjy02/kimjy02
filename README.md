## 김주연

데이터로 문제를 찾고, 직접 확인한 뒤, 실제로 바뀌었는지까지 보는 일을 좋아합니다.<br>
통계학을 전공했고 SSAFY 14기 데이터 트랙을 수료했습니다.

`R` `Python` `SQL` `PostgreSQL` `GA4` `React`

<br>

### 경력

**국민건강보험공단 청년인턴** · 건강관리팀 (2026.07 ~ )
- 사업장 60여 곳 출장 경로를 생성형 AI로 묶고, 결과를 지도에 직접 찍어 확인하며 잘못 묶인 사업장을 다시 나눔
- 경로를 짜는 시간을 2~3시간에서 10분 이내로 줄였고, 못 간 사업장은 다시 배치해 모든 사업장 방문 완료

<br>

### 프로젝트

**PHOSOM** · 내 손 안의 포토부스 (2026.04 ~ 2026.06) · SSAFY 자율프로젝트 우수상
- GA4로 홈 화면 이탈률 80%를 발견하고, 추측 대신 첫 화면 시안 4개로 설문(122명) 진행
- 설문 결과를 근거로 인기 프레임·스티커를 홈에 먼저 보여주자고 제안, 개선 후 이탈률 30% 확인
- 촬영 화면 프론트엔드 개발, 전시발표회 부스에서 70건 이상 촬영·인화하며 현장 의견 전달

**AL-MAENG** · 영상 기반 맞춤 도서 추천 (2026.02 ~ 2026.04)
- 유입 경로와 행동을 나눠 기록하도록 click_log를 설계하고, 가중치·시간 감쇠·3단계 추천 로직을 단독 설계
- 팀원이 AI로 만든 도서 분류를 직접 확인해 25권 중 20권 오분류를 찾고, 재분류 후 모두 바로잡음
- [저장소]([링크](https://github.com/kimjy02/AL-MAENG)

**FOODPASS** · 바코드 기반 식품 알레르기 정보 서비스 (2025.12 ~ 2026.02)
- 로그인·회원가입·마이페이지·상품 정보 화면 개발, 5개 언어 다국어 구현
- 프론트엔드 일정이 1주 넘게 밀린 상황에서 팀원과 맡을 범위를 나눠 합의하고 일정 안에 배포
- [저장소]([링크](https://github.com/kimjy02/FOODPASS)

**도서관 데이터 분석 공모전** · 숭실대학교 도서관 (2024.12 ~ 2025.02)
- 인기 대출·베스트셀러 데이터를 소장 목록과 비교해 도서관에 없는 인기 도서 분석
- 출처마다 제목 표기가 달라 생긴 매칭 오류를 정제 함수로 바로잡아 중복 104건을 걸러내고 미보유 도서 396권 확정
